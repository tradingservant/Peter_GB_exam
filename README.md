# Peter_GB_exam

Classroom practice for a Hong Kong P6 pupil: conditionals (zero, first and second) and the adverbs *too* / *either*. Directions on the page are in formal Traditional Chinese. Questions and answers use British school English.

Answers are visible in the frontend source (`data/exercises.json`, `js/marking.js` and `js/app.js`). This is classroom practice, not an anti-cheating exam and not a central mark book. Scores and progress stay in the page’s memory only. Reset and reload clear them. The page does not ask for a name, email or class code, and it does not upload answers.

## Open the page

Serve this folder with any static file server and open `index.html`. The stylesheet is `css/styles.css`. Relative links are ready for a `/Peter_GB_exam/` subpath later. This repository does not publish the site.

## Tests

Install dependencies, then run the content, marking and headless browser checks:

```
npm install
npm test
```
